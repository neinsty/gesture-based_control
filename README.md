# gesture-based_control

Репозиторий содержит две программы - для управления одним прибором одной рукой и для управления несколькими приборами двумя руками.

для данных программ использовался световой прибор EN SI-039 LEDWASH 324 с 13 каналами управления

управление производилось через ArtNet, подключенный к ноутбуку по Ethernet

жесты распознаются с помощью библиотеки mediapipe, формирование dmx-файла с помошью stupidArtnet

в программе с управлением несколькими приборами наблюдается проблема - для корректной работы необходимо нахождение в кадре только правой руки, поэтому при указании левой рукой номера прибора её нужно убирать, и только после этого начинать движение 


Управление:
1. Запускаем программу
2. Появляется изображение с камеры и выделяются распознанные точки при появлении пальцев
3. Для управления направлением светового прибора оставить в кадре только правую руку, сжать её в кулак, поднять указательный и средний пальцы, соединить их кончики и передвигать в поле зрения камеры
4. Движение вертикально - управление вертикальным движением светового прибора, горизонтально - горизонтальным
5. Для фиксирования нужно развести кончики пальцев, убрать руку из поля зрения камеры или разжать кулак в ладонь
6. При управлении несколькими приборами показать в кадре левую руку, указать номер прибора количеством поднятых пальцев, не меняя количество поднятых пальцев, убрать левую руку из кадра, далее всё как при управлении одним прибором
